# Live Demo Video Script

Target length: 3–4 minutes.

1. Open https://omyaingle.vercel.app on desktop and show the wallet onboarding
   choices.
2. Connect a Freighter testnet wallet and show the four-step onboarding card.
3. Fund the wallet or show its testnet balance.
4. Open AI Chat and run a balance or portfolio command.
5. Open Spending Limits and demonstrate the wallet guard controls.
6. Open Analytics and show portfolio, activity, and health monitoring.
7. Open Feedback and submit a short test response.
8. Resize to a mobile viewport and demonstrate the bottom navigation.
9. Show both testnet contract addresses on Stellar Expert.
10. End on the public GitHub README and test/CI badge.

Upload the recording to an accessible YouTube, Loom, or Google Drive URL and add
the link to the README and `SUBMISSION.md`.
